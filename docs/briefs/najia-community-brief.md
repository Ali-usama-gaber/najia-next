Design a premium, modern, emotionally engaging Arabic-first website for “Najia Community” (مجتمع ناجية), a Saudi community supporting women living with and surviving breast cancer.

IMPORTANT:
This is a community-focused website, NOT a doctor profile website.
The community and the survivor experience must always be the visual and UX priority.
The founder may appear only as a supporting credibility/founding element, never as the main focus.

==================================================
1. PROJECT GOAL
==================================================

Create a website that feels like a living, safe, supportive community rather than a traditional medical or charity website.

The experience should communicate:

- Safety
- Hope
- Trust
- Human connection
- Recovery
- Empowerment
- Knowledge
- Confidence
- Community

The core concept is:

“Care does not end when treatment ends.”

Arabic:
“الرعاية لا تنتهي بانتهاء العلاج”

The website should guide the user through an emotional and intuitive journey:

DISCOVER → UNDERSTAND → FEEL SAFE → EXPLORE → CONNECT → PARTICIPATE

The UX must be simple and intuitive even though the visual experience is rich and highly interactive.

==================================================

==================================================
3. DESIGN DIRECTION
==================================================

Create a sophisticated editorial-style digital experience.

Avoid:
- Generic hospital websites
- Generic charity websites
- Overly clinical layouts
- Excessive pink breast-cancer clichés
- Childish feminine aesthetics
- Template-looking cards everywhere
- Excessive text
- Visual clutter

Prefer:
- Large editorial typography
- Strong whitespace
- Elegant composition
- Layered layouts
- Large imagery
- Soft depth
- Premium cards
- Rounded corners where appropriate
- Subtle glassmorphism
- Smooth transitions
- Strong visual hierarchy
- Cinematic storytelling
- Human-centered imagery

The website should feel contemporary and internationally designed while remaining culturally appropriate for Saudi women and Arabic users.

==================================================
4. TYPOGRAPHY
==================================================

Primary Arabic font:
Cairo

Use Cairo consistently throughout the Arabic interface.

Typography hierarchy:

Display
H1
H2
H3
Body Large
Body
Caption

Use:

- Bold / SemiBold for section headings
- Regular for body copy
- Medium / SemiBold for buttons and labels

Typography should be highly readable and spacious.

Arabic is the primary language.

The layout must support RTL properly.

English can exist as a secondary language, but Arabic must remain the primary design direction.

11. HERO MOTION
==================================================

Use sophisticated motion from the first screen.

On page load:

1. Logo appears smoothly.
2. Hero visual enters with depth.
3. Headline reveals progressively.
4. Supporting text fades/slides in.
5. CTA buttons appear with subtle motion.

Use:
- Text reveal
- Fade
- Scale
- Parallax
- Depth
- Soft floating elements

Avoid excessive bouncing or distracting effects.

==================================================
25. RESPONSIVE UX
==================================================

Design desktop-first but fully responsive.

Required:
- Desktop
- Tablet
- Mobile

On mobile:
- Simplify complex interactions
- Preserve storytelling
- Keep navigation extremely simple
- Avoid excessive animation that hurts performance
- Maintain RTL
- Keep CTAs easy to reach
- Preserve readability and accessibility

==================================================
26. ACCESSIBILITY
==================================================

Prioritize:

- Strong readability
- Appropriate contrast
- Large touch targets
- Clear focus states
- Keyboard navigation
- Reduced motion consideration
- Clear form validation
- Logical information hierarchy

Provide a reduced-motion alternative for users who prefer less animation.
