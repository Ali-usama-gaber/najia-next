STEP 03 — INTERACTIONS, ANIMATIONS & FULL WEBSITE PROTOTYPE

IMPORTANT:

The website structure and UI design are already established.

DO NOT redesign the website.

DO NOT change the existing visual identity.

DO NOT create a new design system.

DO NOT change the approved Homepage or internal page layouts unless a small adjustment is necessary to support interaction or usability.

Your task in this step is to transform the existing Najia website from static UI into a polished, interactive, premium digital experience.

Use the existing design system as the MASTER reference.

==================================================
1. MAIN OBJECTIVE
==================================================

Add a complete interaction and motion system across the entire website.

The experience should feel:

- Premium
- Smooth
- Human
- Emotional
- Modern
- Calm
- Interactive
- Fast
- Culturally appropriate

Animation should support the story and UX.

Do NOT add animation simply for decoration.

The user should always understand:

- What is clickable
- What changed
- Where they are
- Where they are going
- What action they can take

==================================================
2. GLOBAL MOTION SYSTEM
==================================================

Create ONE unified motion language for the entire website.

Use consistent:

- Duration
- Easing
- Movement distance
- Opacity transitions
- Scale behavior
- Reveal behavior

Recommended motion hierarchy:

MICRO:
100–250ms

For:
- Buttons
- Icons
- Hover
- Small UI feedback

STANDARD:
300–600ms

For:
- Cards
- Images
- Text
- Section reveals

SIGNATURE:
600–1200ms

For:
- Hero
- Storytelling
- Timeline
- Major transitions

Avoid excessive or slow animations.

==================================================
3. PAGE LOAD ANIMATION
==================================================

When any page opens:

Use a subtle and consistent page-entry animation.

Suggested sequence:

1. Page background appears.
2. Main visual enters.
3. Main heading reveals.
4. Supporting text appears.
5. CTA appears.

Use:

- Fade
- Translate
- Scale
- Mask reveal

Do NOT make every element animate separately.

The animation should feel coordinated.

==================================================
4. PAGE TRANSITIONS
==================================================

Because Najia is a MULTI-PAGE WEBSITE:

Navigation between pages must use a smooth page transition.

Example:

Homepage
→ Click "المصادر"
→ Resources Page

Use a subtle:

Fade / Slide / Shared transition

The transition must be:

- Fast
- Smooth
- Premium

Do not create long cinematic transitions that slow down navigation.

IMPORTANT:

Navigation between pages is NOT the same as scrolling.

Scrolling happens inside a page.

Navigation changes the page.

==================================================
5. HEADER INTERACTIONS
==================================================

The Header must be interactive.

Desktop:

- Navigation hover states
- Active page state
- CTA hover
- Logo interaction

On scroll:

Header should smoothly transition into a compact/sticky state.

Possible behavior:

Top:
Transparent / spacious

After scrolling:
Compact / elevated / slightly blurred or solid background

Maintain readability.

==================================================
8. CARD INTERACTIONS

- Content reveal

- Image movement
- CTA reveal

- Image zoom

For Creative Cards:

- Product/image movement
- Subtle elevation

All cards must use the same interaction language.

==================================================
9. HERO INTERACTION
==================================================

The Homepage Hero should be the strongest motion moment.

On load:

- Logo / visual reveal
- Headline line-by-line reveal
- Supporting text fade
- CTA reveal
- Visual depth

During scroll:

Use subtle parallax.

Foreground:
Moves slightly.

Background:
Moves slower.

Do NOT overdo parallax.

On mobile, reduce or disable heavy parallax.

المعرفة

21. ICON SYSTEM
==================================================

IMPORTANT:

NO EMOJIS ANYWHERE.

If any existing section contains emojis, replace them.

- Consistent proportions
- Rounded joins

The icon system must be shared across the entire website.

Do not mix different icon styles.

25. SCROLL BEHAVIOR
==================================================

Use scroll animation strategically.

Recommended:

Hero:
Parallax

Storytelling:
Sticky sections

Timeline:
Progressive reveal

Cards:
Reveal on viewport

Impact:
Count-up

Images:
Subtle movement

Do NOT animate every section.

Create rhythm:

Strong motion
↓
Quiet section
↓
Strong motion
↓
Quiet section

This creates a premium experience.

==================================================
26. REDUCED MOTION
==================================================

Respect accessibility.

Provide a reduced-motion behavior.

When reduced motion is preferred:

- Remove heavy parallax
- Reduce large transforms
- Reduce transition duration
- Use simple fades
- Keep content accessible

Never hide important information behind animation.
