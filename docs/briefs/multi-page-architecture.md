IMPORTANT — MULTI-PAGE WEBSITE ARCHITECTURE

There is a very important UX requirement that must be followed.

This website is NOT a single-page scrolling website.

Do NOT treat the navigation tabs as scroll anchors inside the homepage.

The website must be designed as a REAL MULTI-PAGE WEBSITE.

========================================
1. CORE ARCHITECTURE
========================================

The Homepage is a standalone page.

The Homepage contains previews / introductions to different areas of Najia.

Whenever a section represents a major area of the website, it must have a clear CTA that navigates to a SEPARATE PAGE.

Example:

Homepage
↓
Knowledge Preview
↓
"اكتشفي المعرفة"
↓
Knowledge Page

NOT:

Homepage
↓
Knowledge section
↓
scroll further

The Homepage should introduce the content, not contain the entire content of every section.

6. DO NOT MAKE EVERYTHING A BUTTON
========================================

Do not add unnecessary CTAs everywhere.

"شاهدي جميع القصص"

========================================
7. PAGE TRANSITIONS
========================================

When navigating between pages, use a smooth premium page transition.

The transition should feel like one connected digital experience.

Use:

- Fade
- Soft slide
- Shared visual transition
- Subtle page reveal

Avoid dramatic transitions that slow down navigation.

The website should feel fast.

========================================
21. IMPORTANT DISTINCTION
========================================

There are TWO different types of scrolling:

TYPE 1 — NORMAL PAGE SCROLL

Used to move through content inside the current page.

Example:

Home
Hero
↓
Introduction
↓
Community Preview
↓
Stories Preview
↓
Events Preview

This is normal scrolling.

TYPE 2 — PAGE NAVIGATION

Used when the user selects a major website area.

Example:

Home
↓
Click "المعرفة"
↓
NEW PAGE: Knowledge

Home
↓
Click "القصص"
↓
NEW PAGE: Stories

Home
↓
Click "الفعاليات"
↓
NEW PAGE: Events

These must NOT be converted into scroll anchors.

========================================
22. HOMEPAGE SHOULD FEEL COMPLETE
========================================

Even though the Homepage contains previews, it should still feel like a complete experience.

The Homepage tells the Najia story.

The internal pages provide depth.

Think of the architecture as:

HOMEPAGE
= Discover + Storytelling + Direction

INTERNAL PAGES
= Explore + Learn + Participate

========================================
23. UX PRINCIPLE
========================================

The user should never wonder:

"هل هذا Section أم Page؟"

Use clear CTA language.

If the content is a preview:
show a concise preview + CTA.

If the content requires deeper exploration:
open a dedicated page.

Do not create extremely long single-page sections just to avoid creating pages.
